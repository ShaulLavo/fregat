# File and folder picker

The web picker (`components/file-picker-dialog.tsx`, `features/file-picker/**`) opens from the project menu's **Open folder…**; the desktop shell uses the native dialog instead. Columns (the default when choosing a folder, setting `files.picker.view`), a list with sortable headers, or an icons grid, a places sidebar (Root, Home, then the Desktop, Documents and Downloads that `GET /fs/places` finds on the browsed machine, at their XDG paths), and a preview pane that shows content: an image through `/fs/blob`, the head of a text file through `/fs/head` (up to `files.previewKilobytes`, with line numbers and a "First 64 KB of …" note, scrolling both ways), or a folder's children from the cached listing. Every row, tile and preview wears the file tree's glyph (`iconForEntry`). Places, browsing area and preview are a persisted `file-picker` panel group; each column has its own width for the session (`WidthHandle`, double-click fits). The preview follows the selection only once it rests. The footer counts the listing ("N items", "N results" while searching). ⌘[ and ⌘] go back and forward, ⌘↑ goes up and ⌘↓ opens.

`scenario file-picker` checks the list's single focus target and row semantics. `scenario file-picker-browse` builds a fixture folder, walks the columns with → ↓ ←, switches to List and requires the code, image and folder previews, the item count and the three chords, then moves through the icons grid. It also drags a column handle (and double-clicks it to fit) and both pane handles, reopens the picker and reads the pane sizes back, and scrolls a long file's preview to its end and right edge. `scenario file-picker-appearance` screenshots the file tree, the picker on the same folder, and a long-file preview in light and dark, cozy and compact.

Choosing files (the composer's **From <machine>…**, `files` on `FilePickerDialog`) lists files and folders in the list view only, opens in the project, and leaves recent folders to the Places sheet. A click, tap or Space chooses a file or takes it out (`aria-checked`, a check mark); a folder opens on double click, → or Enter, or one tap on a phone. Chosen files stay chosen across folders up to the caller's limit, and the footer's **Attach N files** commits them. Enter or a double click on a file attaches the chosen files together with that file.

`choose-files.browser.tsx` drives that mode in Chromium at desktop and phone widths against the fixture server. `scenario machine-file-attach` and `scenario phone-machine-file-attach` drive it from the composer.
