# site

The Fregat landing page at [fregat.shaulavo.dev](https://fregat.shaulavo.dev/), built with Astro. It has an animated replica of the workbench and no live app.

```sh
bun run --cwd apps/site site:dev     # http://localhost:4321/fregat
bun run --cwd apps/site site:build
```

[Production product sites](../../scripts/product-sites/README.md) covers the Cloudflare Workers deployment for this site and the Singapore and ghostty-webgpu sites.
