# Kokonut UI

Researched 2026-09-25. Source: `references/kokonutui` (shallow clone of
github.com/kokonut-labs/kokonutui @ 83eec6d, 2026-08-20), plus `kokonutui.com/llms.txt`.

## 1. What it is

- shadcn-registry component collection (`npx shadcn add @kokonutui/<name>`), ~46 components + 4 hooks.
  Copy-paste, not a package. Showcase-leaning: heroes, cards, text effects, a few AI widgets.
- License: **MIT** (free repo). `kokonutui.pro` sells templates (Agenta, Lume, …); not needed here.
- Stack: Next 16, React 19, Tailwind v4, `motion` 12, `lucide-react`, shadcn (Radix) `button`/`dropdown-menu`/`tooltip`.
- 35 of 46 components import `motion/react`. The CSS-only ones: `ai-loading`, `command-button`,
  `gradient-button`, `morphic-navbar`, `liquid-glass-card`, `switch-button`, `tweet-card`, `card-flip`.
- Styling is palette-literal throughout (`text-zinc-600`, `bg-red-100`, `#1F9CFE`, `rgb(0,0,0)` + `dark:` twins),
  borders everywhere, no reduced-motion handling. Nothing is copy-able verbatim under our design language;
  every steal is "port the idea".

## 3. Where we stand on the loaders

The working tree has an **in-flight, uncommitted** consolidation (another session): `orbit-loader.tsx` and
`ring-loader.tsx` are deleted and replaced by `packages/ui/src/components/spinner.tsx` +
`spinner-*` utilities in `packages/ui/src/styles/globals.css`. It is already the Kokonut port:

| Kokonut                                               | Ours (Spinner, in flight)                                                                 | Gap                                                                                                                                                               |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `loader.tsx` 4 masked conic rings + breathe           | `size='lg'` → `spinner-ring-1..4`, identical mask stops and periods, `app-loader-breathe` | none; ours tokenizes colour (`--spinner-1..4` = primary rotated 70° steps in oklch, mixed 20% toward muted) and has one ring set instead of light/dark duplicates |
| `ai-loading.tsx` concentric dashed multi-colour rings | `xs–md` → 3 SVG bands, `strokeWidth 2.5`, overlapping, hue-rotated primary                | we spin at 1.9–3.1 s vs Kokonut's calm 8 s + staggered delays; **determinate mask not ported**                                                                    |
| `ai-loading.tsx` scrolling log                        | —                                                                                         | not ported                                                                                                                                                        |
| `ai-text-loading.tsx` cycling verbs                   | `Shimmer` (sweep only)                                                                    | label change is a hard cut                                                                                                                                        |
| `shimmer-text.tsx`                                    | `text-shimmer` utility                                                                    | ours is better (45% band, reduced-motion fallback, no motion dep)                                                                                                 |
| Loader title/subtitle staged fade-in                  | `LoadingState` / `Spinner label` is aria-only                                             | whole-surface wait has no visible "what"                                                                                                                          |
| reduced motion                                        | none                                                                                      | ours slows instead of freezing — keep                                                                                                                             |

Old pre-consolidation primitives (`OrbitLoader`, 3 monochrome dashed rings; `RingLoader`, Kokonut rings 2+3) are
superseded; the comparison above is against `Spinner`.

## 4. Steal list (ranked)

1. **Determinate Spinner (`value` 0–1).** Port the `ai-loading` mask idea: wrap the bands in an SVG `<mask>` whose
   circle has `stroke-dasharray = value·C` (use `useId` for the mask id). Rings keep turning, the revealed arc
   says how far. Surfaces with a known end: attachment upload (`features/chat/components/chat-input-attachment-list.tsx`),
   LSP/font downloads, indexing. Change: `packages/ui/src/components/spinner.tsx` + one CSS rule. **Port idea.**
   Needs a rule line in AGENTS.md "Loading" (determinate vs indeterminate).
2. **Label hand-off inside `Shimmer`.** When a live status label changes (Thinking → Running `bun test` → Writing),
   old text exits up, new enters from below — `ai-text-loading`'s `y 20→0` at our scale (≈4px, `--duration-enter`,
   `ease-out-strong`), CSS keyed span + `@starting-style`, no motion. Only on real state changes; never cycle fake
   verbs as Kokonut does. Surfaces: `features/chat/components/live-activity-row.tsx`, `chat-panel-status.tsx`,
   `composer-activity-status.tsx`. Primitive change: `packages/ui/src/components/shimmer.tsx` (optional `key`-driven
   swap). **Port idea.**
3. **Live tail for running tool calls.** `ai-loading`'s 3-line window: last N lines of a running command's output,
   line numbers muted, top edge faded with `mask-image: linear-gradient(transparent, black 30%)` (a mask, not a
   white/black overlay, so it works on wallpaper). Surface: the collapsed `live-activity-row.tsx` / `activity-row.tsx`
   while `activity.active`. Real data only. **Port idea.**
4. **Whole-surface wait with a caption.** Kokonut `loader.tsx` pairs the lg rings with a title + subtitle that fade
   in late (0.4–0.8 s), so a fast load never shows words. For `Spinner size='lg'` at boot / machine connect
   (`components/application-bootstrap.tsx`): caption `text-xs text-muted-foreground`, enters after ~400 ms.
   Must not read as an EmptyState (loader present, different type). **Port idea; owner call** (see Q2).
5. **Hold-to-confirm for destructive bulk actions.** Fill `bg-destructive/15` via `scale-x` transition while held
   (JS timer fires the action; CSS draws the fill), releases in `--duration-exit`. Candidate: git "Discard all"
   (currently a confirm dialog). Keyboard path must stay (Enter on a focused hold button = open the existing dialog).
   **Port idea, low priority** (see Q3).
6. **Expanding toggle chip** (`toolbar.tsx`, `ai-input-search.tsx`): an `aria-pressed` chip shows its label only when
   on, width animating via `grid-template-columns: 0fr→1fr` or `interpolate-size: allow-keywords`. Candidate: composer
   mode toggles in `chat-input-actions.tsx`. **Port idea, low.**
7. **Slide-swap label** (`slide-text-button.tsx`): CSS-only vertical swap, e.g. `Copy` → `Copied` on the copy
   buttons. **Port idea, low.**

Skip: backgrounds, text effects, cards, `liquid-glass-card` (floating surfaces must be opaque; `url()` backdrop filter
is Chromium-only), `command-button` (palette colours + border + decorative sweep), `action-search-bar` (staggered
height-auto row entry fights the no-flicker/keepPreviousData rule and cmdk), `morphic-navbar`, particle/magnet/
gradient buttons, `smooth-drawer` (vaul), `use-auto-resize-textarea` (our `Textarea` already uses
`field-sizing-content`).

## 5. Cost / risk

- Zero new dependencies for every item above; Kokonut's motion usage is all loops/tweens CSS already covers.
- Design-language conflicts to strip on any port: palette literals and `dark:` twins → tokens; `border` → tone;
  hand-written durations (0.3/0.4/2.5 s) → `--duration-*` + `ease-*-strong`; add reduced-motion (slow, not stop).
- `ai-loading` runs 6 infinite animations per instance plus a 2 s `setInterval` with state churn; the tail (item 3)
  must be driven by real output events, not a timer.
- Determinate mask: SVG masks re-rasterize per frame while the rings spin; at 16 px negligible, measure at lg with
  `agent:browser trace` before shipping.

## 6. Open questions for the owner

1. Spinner speed: Kokonut's `ai-loading` turns at 8 s with staggered delays (calm); the in-flight Spinner turns at
   1.9–3.1 s. Want the calmer rhythm for the chat "agent working" mark specifically?
2. May a whole-surface `Spinner size='lg'` carry a visible caption (item 4), or stay aria-only per the current
   "no bare Loading… paragraph" rule?
3. Hold-to-confirm (item 5): replace the discard confirm dialog, or skip?
4. Determinate progress (item 1): as a Spinner mode, or a separate linear `Progress` primitive (we have none)?
