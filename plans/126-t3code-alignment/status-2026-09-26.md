## How this was measured

Every scenario a partial row depends on was run today with `bun run agent:browser scenario …`
against a per-run throwaway API server. The first runs used the shared Vite on 5173 from the main
checkout. That Vite went down at 09:33Z, when systemd-oomd killed a 6.4 GB scope, so later
runs used a private Vite on port 5226 served from a clean `origin/main` worktree. Evidence is under
`/work/tmp/fregat-evidence/20260926T09*`; every screenshot cited below was read.

Most of the older scenarios no longer run on `main`, and the product is not the cause. Seven
harness defects, each found by a failing run and confirmed by a green run after a local patch.
The patch is `/work/tmp/research2/126/scenario-harness-fixes.patch` and is not committed.

`agent:browser` run hit it; the mesh is same-origin and does not. `file-attachments` fails there.
