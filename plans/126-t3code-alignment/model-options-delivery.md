# Advertised model options and service tiers

RUNTIME-06 is in progress against T3 Code `7445aa733ada33e45289e5aa5055f79142556513`. This batch carries the provider's option descriptors through discovery, composer controls, saved selections and native requests.

The descriptor contract preserves select and boolean options, provider IDs, labels, descriptions and defaults. Codex advertises its reasoning levels and service tiers, including the Standard choice. Explicit tier selections use the provider's exact ID. Clearing a select choice leaves the native parameter absent. Model changes discard unsupported explicit choices and use the new model's advertised defaults. Untouched select and boolean choices remain absent in the persisted generic selection; the UI displays their defaults. Provider adapters resolve native defaults where their protocol requires them.

The five implemented Claude model profiles match their rows in the pinned manifest. The adapter resolves advertised effort/context defaults and retains the `[1m]` model suffix for one-million context. Explicit Fast Mode reaches native settings as `fastMode: true`; Haiku's Thinking choice reaches `alwaysThinkingEnabled`. Ultracode maps to xhigh effort and its native setting. Ultrathink uses prompt injection, with composer controls reflecting that choice and explaining how to unlock it when it comes from the message text. Focused tests cover these paths; the browser run below uses the Codex protocol fixture.
