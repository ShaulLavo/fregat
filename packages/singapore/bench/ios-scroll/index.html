What these measurements mean

Lag compares mounted row geometry with scrollTop on the main thread. It is a DOM proxy. JavaScript cannot read the compositor's actual displayed frame. Blank pixels measure missing row coverage, including paint that has yet to catch up. A screen recording and your observation decide whether scrolling looks steady.

The native document setting changes only the probe's CSS. Horizontal scrolling and editor overlays need separate verification before any production use. Overscan comes from a probe-only bundler override. The editor package source stays unchanged. Long tasks are reported only when the browser supports that API.

Geometry reads can force layout. Repeat a baseline with reads off to check observer overhead. Scripted controls use scrollBy and do not reproduce a finger fling.
