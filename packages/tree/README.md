# @workspace/tree

The file tree used by the web app and the terminal client: a controller, a prepared-input path store, layout and sticky rows, Git status and drag selection. It is a product-owned fork of Pierre's tree and path-store packages. Private to this repository.

```sh
bun run --cwd packages/tree test
```

[`UPSTREAM.md`](UPSTREAM.md) records the fork point and how to port upstream changes.
