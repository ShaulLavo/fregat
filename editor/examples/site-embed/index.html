Singapore embed prototype

The editor loads when this example enters view. Edit it or hover a function to start TypeScript. 

import { createPieceTableSnapshot, insertIntoPieceTable } from '@singapore-editor/textbuffer'

const original = createPieceTableSnapshot('hello')
const edited = insertIntoPieceTable(original, 5, ' world')

Build with bun editor/examples/site-embed/build.ts. Serve the generated folder with any static HTTP host.
